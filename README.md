# Uthsha Chatterjee — Portfolio

This is a static website. No installation or build step is required.

## Preview locally

Open `index.html` in a web browser. Keep `styles.css`, `script.js`, and the `assets` folder beside it.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new repository, for example `uthsha-portfolio`.
2. Upload the contents of this folder to the repository's root. The `index.html` file must be at the root, with `styles.css`, `script.js`, and `assets` beside it.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub finishes publishing, the site address appears on the Pages settings screen.

The site and documents in `assets` will be public to anyone with the website link. Remove any file you do not want to share before publishing.
